# 🌍 Language Translation Tool

A web-based language translation application developed using Python, Flask, HTML, CSS, and JavaScript.

The application allows users to enter text, select source and target languages, translate the text using a translation API, and use additional features such as copying and text-to-speech.

## ✨ Features

- 🌐 Translate text between multiple languages
- 🔄 Swap source and target languages
- 📋 Copy translated text
- 🔊 Text-to-speech
- 🧹 Clear input text
- 📚 Translation history
- 🔢 Character counter
- ⏳ Loading indicator
- ❌ Error handling
- 📱 Responsive user interface
- 📝 Long-text translation support

## 🌎 Supported Languages

- English
- Telugu
- Hindi
- Tamil
- Kannada
- Malayalam
- French
- Spanish
- German

## 🛠️ Technologies Used

### Frontend

- JavaScript

### Backend

- Requests
